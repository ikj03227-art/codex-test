# Codex Cloud 動作確認アプリ

iPhone 14 Plusを含むスマートフォンで使える、シンプルな動作確認用Webアプリです。ボタンを押した回数はブラウザの `localStorage` に保存されるため、ページを再読み込みしても維持されます。

## 起動方法

外部ライブラリやビルドは不要です。リポジトリのルートで次のコマンドを実行してください。

```bash
python3 -m http.server 8000
```

その後、ブラウザで <http://localhost:8000> を開きます。同じネットワーク上のiPhoneから確認する場合は、`localhost` をサーバーを起動した端末のIPアドレスに置き換えてください。

## 動作確認

1. 画面中央に「スマホだけでCodex Cloud成功！」と表示されることを確認します。
2. 「カウントする」ボタンを押すたび、表示回数が1ずつ増えることを確認します。
3. ページを再読み込みし、直前の回数が復元されることを確認します。

回数をリセットするには、ブラウザのサイトデータからこのページの `localStorage` を削除してください。
